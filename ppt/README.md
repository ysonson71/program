# AI 원페이지 파워포인트 슬라이드 생성기 (AI PPT Generator)

보고서, 기획안, 전략 내용 등의 텍스트를 입력하면, Google Gemini AI가 핵심 내용을 파악하여 **단 1장의 비즈니스 파워포인트(.pptx) 슬라이드**로 자동 구조화 및 생성해 주는 프로그램입니다.

---

## 🌟 주요 기능 및 규격

1. **0단계: 3개 작성 언어 지원**
   - **🇯🇵 일본어 (기본 디폴트)**: 비즈니스 체언지(体言止め) 기반 간결한 일본어 장표
   - **🇺🇸 영어**: 글로벌 비즈니스 스타일의 명사구/동명사구 기반 영문 슬라이드
   - **🇰🇷 한국어**: 깔끔한 개조식(명사형 종결) 기반 국문 보고 슬라이드
2. **1단계: 3가지 슬라이드 레이아웃 선택**
   - **1) 📊 표(Table) 형식**: 프러시안 블루 헤더와 깔끔한 검은색 테두리의 데이터 표 구성 (헤더·본문 14pt 고정)
   - **2) 🖼️ 내용 + 그림 (오른쪽 그림 50%)**: 좌측(50%)에 내용 정리(소제목 15pt, 본문 13pt), 우측(50%)에 그림/도표 삽입용 점선 가이드 영역 제공
   - **3) 📐 내용 + 그림 (상하 30:70)**: 상측(30%)에 핵심 요약 내용(소제목 13.5pt, 본문 12pt), 하측(70%)에 대형 다이어그램/그림용 넓은 점선 가이드 영역 제공
3. **폰트 표준화**
   - 모든 제목, 본문, 표, 가이드 문구를 **Meiryo UI** 폰트로 통일
4. **비즈니스 디자인 규격 준수 (16:9 와이드)**
   - 메인 제목 (24pt 볼드, 왼쪽 맞춤)
   - 제목 아래 **■ 핵심 1줄 요약문** (16pt 볼드, 리드문/결론)
   - 제목과 본문 사이의 불필요한 분리선 제거로 깔끔하고 세련된 여백 확보
   - 내용 입력창은 빈 칸으로 제공되어 즉시 붙여넣기 가능

## 🚀 로컬 실행 방법

### 방법 1: 크롬(Chrome) 브라우저에서 바로 실행 (추천)
- `run_in_chrome.bat` 파일을 더블클릭하거나,
- `index.html` 파일을 크롬 브라우저로 열기만 하면 파이썬 없이도 즉시 실행됩니다.

### 방법 2: 파이썬 로컬 서버 방식
- `run_ppt.bat` 파일을 더블클릭하거나 터미널에서 `ppt` 입력 시 로컬 서버 구동 및 크롬 자동 실행
